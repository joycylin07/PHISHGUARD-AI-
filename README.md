# PHISHGUARD-AI-
PHISHGUARD AI

PHISHGUARD AI is an AI-powered phishing detection system designed to identify potentially malicious URLs and help users stay protected from phishing attacks.

Features

- Phishing URL detection
- AI/ML-based threat analysis
- Scan history storage
- Security dashboard
- Threat statistics
- Recent scan history
- Database-backed scan records

Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Machine Learning

Project Structure

PHISHGUARD-AI/
├── database/
│   ├── database_schema.sql
│   └── db_connection.py
├── app.py
├── README.md
└── requirements.txt

Database

The database component stores scan information and supports the security dashboard.

The database includes:

- Scan history
- URL information
- Detection results
- Threat-related statistics
- Dashboard data

How to Run

1. Clone the repository.
2. Install the required Python packages.
3. Configure the MySQL database.
4. Run the Flask application.
5. Open the application in a web browser.

Project Goal

The goal of PHISHGUARD AI is to provide users with a simple and effective way to identify phishing threats and understand their security status through a dashboard.
